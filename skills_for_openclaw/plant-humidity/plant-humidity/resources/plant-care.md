# 🌿 植物土壤湿度护理指南

## 通用土壤湿度标准

| 湿度范围 | 状态 | 建议 |
|---------|------|------|
| < 30% | 🔴 过干 | 立即浇水，土壤已严重缺水 |
| 30-50% | 🟡 偏干 | 适量补水，植物开始口渴 |
| 50-70% | 🟢 良好 | 保持现状，植物处于舒适区 |
| 70-90% | 🟡 偏湿 | 减少浇水，注意通风防霉 |
| > 90% | 🔴 过湿 | 停止浇水，有烂根风险 |

## 小红花（假设为常见室内观叶植物）

- **理想湿度**：50% - 70%
- **浇水频率**：见干见湿，土表2-3cm干了再浇
- **季节调整**：
  - 夏季：蒸发快，可适当提高浇水频率
  - 冬季：生长慢，减少浇水

## 注意事项

1. 传感器读的是土壤湿度，不是空气湿度
2. 不同土壤介质（泥炭、椰糠、园土）保水性不同，阈值略有差异
3. 盆器材质影响：陶盆透气但干得快，塑料盆保水但易闷根
4. 最佳浇水时间：早晨，避免晚上（易烂根）
